CURRENT FORENSIC POSITION
======================================================================

The synthetic evidence is consistent with suspicious privileged activity.

The following remain unresolved:

- Malicious insider vs compromised account
- Workstation compromise vs legitimate workstation use
- Whether data actually left the organization
- Exact number of affected patients
- Exact PHI categories exposed
- Whether any records were modified/deleted
- Root cause of the audit gap
- Source of geographic/session inconsistency
- Human or external actor attribution

The 500 GiB USB value represents synthetic telemetry and must not be
treated as proof that 500 GiB of patient data successfully left the
organization.

The blocked SFTP event does not establish successful external
exfiltration.

No specific external actor is attributed.

======================================================================
EVIDENCE HANDLING
======================================================================

Original evidence should be preserved.

Analysis should be performed on forensic copies.

For every evidence item record:
- Evidence ID
- Source
- Acquisition timestamp
- Collector
- Acquisition method
- SHA-256 hash
- Storage location
- Access history
- Purpose of access

All timestamps should be normalized and the original timezone retained.

======================================================================
FINAL PRINCIPLE
======================================================================

The investigation should distinguish:

FACT
Directly demonstrated by evidence.

INFERENCE
Reasonable interpretation supported by multiple sources.

HYPOTHESIS
An explanation requiring further testing.

UNRESOLVED
Insufficient evidence for a reliable conclusion.

This evidence index describes a synthetic defensive cybersecurity lab.
